# Mika's Open Learning Notebook

A living roadmap for self-taught developers, documented while the learning is happening.

I learn by building real software, breaking things, debugging them, and writing down what finally clicks. This repository turns those notes into a public resource: a roadmap, field notes, project trails, longer writing, and dated learning logs.

## Start here

- **Roadmap** — a practical path from fundamentals to shipping real software
- **Field notes** — durable explanations, debugging notes, and mental models
- **Journey** — dated learning logs showing the messy middle in public
- **Projects** — real builds connected back to the skills they taught
- **Writing** — longer essays and articles grown from the notebook

The roadmap is not a checklist of everything in software engineering. It is a guide for building enough understanding to make things, explain them, debug them, and keep going.
